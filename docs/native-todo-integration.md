# Supernote To-do integration

Enable native To-do synchronization and connect Supernote Cloud in SmartyNote Settings. The integration is optional and uses an unofficial cloud API. A locally encrypted session is retained; passwords and verification codes are not saved.

Task edits target existing records and require server confirmation. Native synchronization may take time. Linked notes open through the supported file-opening API when their metadata can be resolved. Exact handwritten-anchor highlighting is not supported; use native To-do when a link cannot be resolved. The plugin does not modify handwritten ink or create a separate task database.

Network access is required for cloud operations. Verify changes in native To-do, and use noncritical tasks when evaluating a prerelease.
