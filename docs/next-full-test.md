# Full dashboard revision (after Build 49)

Items 1–17 from the November 25 mockup; item 18 and the Cloudflare Worker are explicitly deferred. Source artwork is the uploaded 22 SVGs, retained as an exact compressed source bundle and rasterized for React Native. Section headers follow gecko / plant / coffee / crystal / jellyfish / McNuggets. Stardust closes Home and is the plugin launcher. Four ShortCats buttons default to refresh, settings, calendar and search; old six-button settings migrate to those four without touching pins or favorites. Plain pin star and back arrow use existing functional glyphs because the supplied set has no separate equivalents. The supplied cat placeholder is temporarily cropped and scaled to fit.
