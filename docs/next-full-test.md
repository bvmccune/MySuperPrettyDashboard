## Weather, availability and artwork panel
Weather uses Open-Meteo forecast and geocoding endpoints (personal/noncommercial use), configured city coordinates, °F, current WMO code, 15-minute refresh, sunrise/sunset and local daily high/low. No GPS or calendar data is sent to weather service. On error keep the last matching-location snapshot and label it cached; stale current data is hidden after two hours. Availability estimates timed appointments in remaining work hours today or the selected date's full work window; merge intervals, clip at work boundaries, and exclude all-day events because the existing feed has no free/busy flag. Initial city Atlanta, Georgia; initial work hours 09:00–17:00, both adjustable in Settings. Home's right bottom content uses 40/20/40 columns; retains Stardust close header. Artwork reads PNG/JPEG/WebP files from MyStyle/Plugins/MySuperPrettyDashboard/artwork and rotates by local date; one image remains fixed. User-supplied possum art is local-only (third-party redistribution rights unverified). Original calendar feed and workflow unchanged. Weather icon mapping and availability tests run inside existing calendar test entry.
