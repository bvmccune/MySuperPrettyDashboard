# Full dashboard revision (after Build 49)

Items 1–17 from the November 25 mockup; item 18 and the Cloudflare Worker are explicitly deferred. Source artwork is the uploaded 22 SVGs, retained as an exact compressed source bundle and rasterized for React Native. Section headers follow gecko / plant / coffee / crystal / jellyfish / McNuggets. Stardust closes Home and is the plugin launcher. Four ShortCats buttons default to refresh, settings, calendar and search; old six-button settings migrate to those four without touching pins or favorites. The bottom row is shorter; date headings are live. Calendar shortcut opens today's rolling seven-day agenda; tapping an event (including Select) opens details and does not change the Home selected day. Event description/location/attendees are not fabricated if absent from the existing feed. Plain pin star and back arrow use existing functional glyphs because the supplied set has no separate equivalents. The supplied cat placeholder is temporarily cropped and scaled to fit. No changes to bubble, plugin ID, connection credentials or calendar Worker.

## Follow-up icon assignments
ShortCats now uses two columns and three rows. The previous four buttons stay in place, followed by Cloud sync (full content reload, including pins, favorites, calendar, To-do, notes, metadata and status) and Open notebook (latest actual .note modification timestamp, never recent-open history). Existing Refresh retains its behavior. The charging battery uses the approved combined SVG and live fill; standalone lightning is a charging-only fallback when battery percentage is unavailable. Regular notebook stays the note-list icon regardless of recognition mode. Auto-refresh is intentionally not displayed. No Worker changes.
